维护者为本项目有权授予的原创贡献选择 Apache-2.0，根 LICENSE/NOTICE 与 package 元数据保持一致。项目许可证不能替代第三方代码、品牌和素材的授权。

系统管理页面基于 API/行为契约使用 Vue 3、Ant Design Vue 等公开依赖实现，图标由本地 Ant Design 图标库提供。当前运行源码没有私有 JetLinks UI 依赖、远程 iconfont 或内置字体。原系统管理实现和 API 包装的参考/迁移关系，仍需由维护者确认可公开范围；本地迁移授权不自动等同于第三方公开许可。

`pnpm verify` 仅检查有限模式和路径，不能认证权属、第三方声明完整性或不存在漏洞。`pnpm build` 附带第三方许可文本与清单，`pnpm sbom` 生成本机安装环境元数据；实际浏览器 bundle、构建依赖和跨平台可选包应分别复核。

源码公开文件集、手动门禁、二进制分发和已知兼容边界见 [发布指南](public/RELEASE.md)。不复制旧仓库 Git 元数据，不提交凭据、运行文件或内部原始证据。
